Project Thesis

Rivu is a Go CLI/TUI control deck for mapping a personal project filesystem into a registry-backed operating system: Flow, Channel, Current, Bank, Map, Delta, and Confluence.

What Must Exist First

  • rivu init --root creates config and database.
  • rivu scan discovers projects and records mismatches.
  • rivu tui renders a useful project list.

What Is Deliberately Later

  • No daemon, cloud sync, vector search, or GitHub automation in v1.
  • No destructive cleanup command. Moves and Delta require previews.
  • No AI chat in the TUI. Agents read deterministic Map files.

Reading path: scan the workspace, reconcile into SQLite, operate through CLI/TUI, generate Map files for agents.

Ponytail version: keep the command/use-case layer thin. CLI and TUI should call the same behavior, not duplicate it.
